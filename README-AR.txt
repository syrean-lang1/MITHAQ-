مشروع تطبيق ميثاق Android — الإصدار المعدّل
==========================

الرابط داخل التطبيق:
https://mithaq-w.vercel.app/

اسم التطبيق: ميثاق
Application ID: com.mithaq.app
الحد الأدنى: Android 6.0 (API 23)
المستهدف: Android 15 (API 35)

طريقة البناء:
1) فك ضغط MITHAQ-ANDROID-COTG.zip داخل الهاتف.
2) افتح Code On The Go واختر فتح مشروع Android/Gradle ثم حدد مجلد MITHAQ-ANDROID-COTG.
3) انتظر مزامنة Gradle. تم ضبط Android Gradle Plugin على 8.11.0 ليتوافق مع سجل بيئتك الحالي الذي يظهر Gradle 8.14.3. إذا كان إصدار Code On The Go لديك قديمًا أو غير مكتمل فقد يلزم تحديث أدوات البناء من داخل التطبيق.
4) نفّذ مهمة :app:assembleDebug.
5) ملف APK الناتج عادةً:
   app/build/outputs/apk/debug/app-debug.apk

ملاحظات:
- هذا تطبيق WebView يحمّل الموقع المنشور مباشرة، وليس نسخة محلية من ملفات الموقع.
- يلزم اتصال إنترنت لاستخدام الموقع.
- رفع الملفات مدعوم عبر منتقي ملفات Android إذا كان الموقع يستخدم حقول رفع ملفات HTML.
- الروابط الخارجية مثل البريد والهاتف تفتح في التطبيقات المناسبة.
- أي تغيير لاحق على الموقع المنشور يظهر داخل التطبيق دون إعادة بناء APK.
- لم يتم تضمين مفاتيح Firebase أو Supabase أو أي أسرار في تطبيق Android.
- ملف APK لم يُبنَ داخل هذه البيئة؛ المشروع جاهز لمحاولة البناء في Code On The Go.


طريقة بديلة للبناء عند تعذر تنزيل Android SDK على الهاتف:
1) ارفع محتويات هذا المشروع إلى مستودع GitHub جديد (Repository) باسم MITHAQ-ANDROID.
2) تأكد أن فرع المستودع اسمه main.
3) افتح تبويب Actions في المستودع.
4) اختر Build MITHAQ APK ثم Run workflow.
5) بعد انتهاء المهمة بنجاح افتح نتيجة التشغيل، ثم قسم Artifacts وحمّل MITHAQ-debug-APK.zip.
6) فك ضغط الملف لتحصل على app-debug.apk.

هذه الطريقة تبني التطبيق على خادم GitHub Actions، حيث يتم تنزيل Android SDK أثناء البناء بدلاً من تنزيله على الهاتف.
